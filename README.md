# Elige tu destino 🎲

Una aplicación interactiva web creada con **HTML5**, **CSS3** y **JavaScript** vainilla.

## 📋 Características

- **Diseño limpio y centrado:** Interfaz visual moderna, adaptable a móviles y escritorios, con transiciones fluidas.
- **Dos botones de elección:** Botón rojo y botón azul con estilos tridimensionales y microinteracciones al pasar el cursor o hacer clic.
- **Lógica aleatoria:** Al pulsar cualquiera de los dos botones, se determina al azar si has ganado o perdido (50% de probabilidad).
- **Botón "Volver a jugar":** Permite reiniciar la partida al instante manteniendo la fluidez del juego.
- **Marcador de estadísticas:** Registra el número de victorias y derrotas acumuladas durante la sesión.
- **Accesibilidad:** Uso de elementos semánticos, navegación completa mediante teclado y regiones ARIA para lectores de pantalla.

## 🚀 Cómo usar

1. Abre el archivo `index.html` en cualquier navegador web moderno (Google Chrome, Firefox, Safari, Edge, etc.).
2. Haz clic en el botón rojo o en el botón azul.
3. Descubre el resultado en pantalla ("Has ganado" o "Has perdido").
4. Haz clic en "Volver a jugar" para probar suerte de nuevo.
